# interview-prep-api

## Project name
interview-prep-api

## Year
2026

## Purpose
Public REST API for interview prep — track coding problems by pattern and difficulty

## Features
- Pattern- and difficulty-based problem catalog
- Auth (JWT / Google), progress tracking, and study guides
- Push reminders and email notifications
- Static Netlify frontend with API proxy to Railway
- Seed and LeetCode brief generation scripts
- Runtime:** Node.js, Express 5

## Tech Stack used
- Express
- Mongoose
